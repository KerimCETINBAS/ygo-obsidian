# Example vault

This folder is an Obsidian vault. It holds a sample deck, an opening combo, and a card-link note.

1. In Obsidian, choose **Open folder as vault** and select `example`.
2. Install and enable Yu-Gi-Oh Combo Builder.
3. [[Deck]] is the deck. [[Opening]] is the playable combo. [[Cards]] shows a card note beside its picture.

The first time a card is shown, it is saved into `cards`. Later pictures and tooltips are read from `card.md` and `card.png` in that folder.

`[[Card Name]]` is a note link. Use `![[Card Name.png]]` for the picture.
